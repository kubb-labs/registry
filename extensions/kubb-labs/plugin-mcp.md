# MCP

Generates a Model Context Protocol (MCP) server from your OpenAPI spec. Each operation becomes a typed tool that AI assistants can call.

The tool handlers call a function generated by a client plugin, and Zod schemas from `@kubb/plugin-zod` validate the tool input. The plugin writes `server.ts` and `.mcp.json` next to the handlers.

## Setup

- Add `@kubb/plugin-ts`, `@kubb/plugin-zod`, and a client plugin: `@kubb/plugin-fetch` or `@kubb/plugin-axios`.
- Install `@modelcontextprotocol/sdk` v1 or higher in the app that runs the server.

## Options worth knowing

- `client` picks `fetch` or `axios` when both client plugins are registered. A single client is detected automatically.
- Keep `output.path` a folder name, such as the default `mcp`. Single-file output has no place for `server.ts` and `.mcp.json`.
